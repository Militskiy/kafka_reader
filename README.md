# Kafka Reader

Kafka Reader позволяет читать сообщения из конкретного топика Kafka. Для работы достаточно доступа к топику и его разделам. Права на группы потребителей не требуются.

[Скачать Kafka Reader для Windows x64](https://github.com/Militskiy/kafka_reader/releases/latest/download/kafka-reader.exe)

## Как начать

1. Запустите `kafka-reader.exe` и нажмите **+ Сервер**.
2. На вкладке **Подключение** укажите имя подключения, адреса брокеров в формате `хост:порт`, протокол безопасности и точное имя топика.
3. На вкладке **Аутентификация** выберите способ входа. Для **PLAIN** и **SCRAM** нужны учётные данные Kafka. Для **OAUTHBEARER** выберите **SASL_SSL**, укажите HTTPS-адрес выдачи токенов и идентификатор клиента. Если у вас доменная учётная запись, выберите **OAUTHBEARER · Логин и пароль** и введите её логин и пароль. Если у вас токен обновления, выберите режим **Токен обновления**.
4. Нажмите **Проверить топик**, затем **Сохранить сервер**. Откройте топик в боковой панели, выберите начальную позицию и нажмите **Читать**.

## Что можно делать

- Читать с начала топика, с заданного смещения или времени. Режим **Следить** показывает новые сообщения по мере поступления.
- Выбирать разделы, фильтровать сообщения и сортировать их по времени, разделу или смещению.
- Просматривать значение, ключ, заголовки и метаданные записи. Доступны JSON, текст и шестнадцатеричное представление.
- Копировать отдельные записи и экспортировать видимые сообщения в JSONL с сохранением исходных байтов.
- Открывать до восьми вкладок, добавлять топики в избранное и переключать язык между русским и английским.

## Как запомнить пароль или токен

В Windows на вкладке **Аутентификация** установите **Запомнить логин и пароль на этом ПК** или **Запомнить токен обновления на этом ПК**, затем нажмите **Сохранить сервер**. При следующем запуске данные будут доступны для этого подключения под вашей учётной записью Windows. Если провайдер заменит токен обновления во время чтения, Kafka Reader сохранит новый.

По умолчанию данные действуют до закрытия приложения. Чтобы удалить сохранённую копию, снимите флажок и сохраните сервер. Пароли и токены не включаются в экспорт профиля.
