# Kafka Reader workspace

The Rust project is in [kafka-reader-source](kafka-reader-source/). Read its
[coding instructions](kafka-reader-source/AGENTS.md) and
[project context](kafka-reader-source/docs/PROJECT_CONTEXT.md) before working
on the application, packaging, or QA fixtures.

Run Cargo, packaging, and verification commands from that directory. The
[development guide](kafka-reader-source/docs/DEVELOPMENT.md) covers platform
toolchains and checks. The [architecture guide](kafka-reader-source/docs/ARCHITECTURE.md)
explains the reader, desktop, and persistence constraints.
