# История изменений

## 0.7.0 — в разработке

- Для OAUTHBEARER можно выбрать вход по доменному логину и паролю. Kafka Reader получает токен доступа у сервера авторизации и повторяет вход во время длительного чтения. Режим доступен в приложении и в CLI.
- В Windows доменный логин и пароль можно запомнить для выбранного сервера. При экспорте профиля сохраняется способ входа, а учётные данные остаются на компьютере.

## 0.6.0 — 23 ноября 2026

- В Windows можно запомнить логин и пароль для PLAIN или SCRAM либо токен обновления для OAUTHBEARER. Флажок на вкладке **Аутентификация** действует только для выбранного сервера. Windows шифрует данные с помощью DPAPI для текущей учётной записи.
- Если сервер авторизации выдаёт новый токен обновления, Kafka Reader сохраняет его вместо предыдущего. После перезапуска вводить токен заново не нужно.
- Чтобы удалить сохранённые данные, снимите флажок и нажмите **Сохранить сервер**. В экспорт профиля пароли и токены не попадают.

## 0.5.0 — 23 ноября 2026

- **Копирование и вставка.** Ctrl+C и Ctrl+V работают с системным буфером обмена. Кнопка вставки рядом с полем добавляет текст в позицию курсора или заменяет выделение. Ею можно вставить адреса брокеров, имя топика, пароль или токен.
- **Вход по токену обновления.** Для подключения по SASL_SSL можно выбрать OAUTHBEARER, указать HTTPS-адрес выдачи токенов, идентификатор клиента и токен обновления. Kafka Reader автоматически обновляет токен доступа во время чтения. Для входа по имени пользователя и паролю доступны PLAIN и SCRAM.

## 0.4.0 — 22 ноября 2026

- Добавлен русский интерфейс. Приложение выбирает язык системы при первом запуске. В настройках можно вручную выбрать русский или английский.
- При чтении большого потока сообщений сохраняются причина остановки и число пропущенных записей. При поиске по времени видны ошибки отдельных разделов.
- Экспорт сохраняет записи выбранной вкладки. Если файл с таким именем уже существует, приложение предложит выбрать другое имя.
- Настройки чтения сохраняются при смене темы. Если рабочая область открыта в двух окнах, более старая копия не перезапишет новые изменения.

## 0.3.0 — 22 ноября 2026

- При первом запуске открывается пустая рабочая область. При обновлении сохраняются подключения, избранное и настройки.
- В списке сообщений появились отдельные столбцы времени, раздела и смещения. Нажатие на заголовок меняет порядок сортировки.
- В инспекторе появились отдельные вкладки для значения, ключа, заголовков и метаданных. Для ключа и значения можно выбрать шестнадцатеричный формат.

## 0.2.0 — 22 ноября 2026

- Добавлены дерево серверов и топиков, избранное, поиск и до восьми вкладок. При переключении сохраняются прочитанные записи и фильтры.
- Параметры подключения, аутентификации и TLS собраны в редакторе сервера. Яркость темы, размер шрифта и ограничения чтения доступны в настройках приложения.
- Добавлен просмотр разделов топика и границ смещений; профиль и список открытых вкладок восстанавливаются после перезапуска.

## 0.1.0

- Чтение Kafka по точному имени топика, просмотр записей и экспорт в JSONL через графический интерфейс или командную строку.
